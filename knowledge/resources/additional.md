Linux Kernel
- central component of operating system that manages the computer and hardware operations. Handles memory operations and cpu time
    - Acts as bridge between application and harware-level data processing 
    - Loads memory first when operating system, starts and remains there until system shutsdown. Responsible to tasks like disk management and memory management
